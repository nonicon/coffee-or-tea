## The entry

Exactly one letter, written to `/output/entry.txt`:

```
A
```

**A = coffee.** No word, no explanation, no punctuation — the gate
requires UTF-8 text of exactly 1 character, and anything else loses
to any letter that chooses coffee or tea.

## Why coffee

Of the two stances, coffee is the bolder, more alive answer — the
morning-fuel, get-up-and-go drink. Against a judge that weighs
vividness first, then humour, then honesty, the letter for the drink
people reach for when they need to feel awake lands as the fuller,
funnier, truer choice.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
